# NetPulse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build NetPulse — a single-process Go utility monitoring interfaces, VPN, Tailscale, and health checks, surfaced via a StatusNotifierItem tray icon/menu plus freedesktop notifications.

**Architecture:** Ticker-driven workers publish typed snapshots into a mutex-guarded `state.Store`; commits emit transition `Event`s to subscribers; two adapters consume — `tray` (icon + D-Bus menu) and `alert` (notifications + event log). Everything testable lives below the adapters.

**Tech Stack:** Go ≥1.22, `godbus/dbus/v5`, `fyne.io/systray`, `go-ping/ping`, `fsnotify/fsnotify`, `BurntSushi/toml`.

**Spec:** `docs/superpowers/specs/2026-10-16-netpulse-design.md` — read it first; this plan argues from it.

## Global Constraints

- User-level process only: no root, no daemon. ICMP via `go-ping` unprivileged datagram socket.
- No GUI toolkit; tray = `fyne.io/systray` (SNI + `com.canonical.dbusmenu`).
- Failure counting: only completed probes that fail increment a check's failure counter; internal worker errors never count as target failures (spec §7).
- Alerts are transition-only: one notification per state change, including recovery.
- Config path `~/.config/netpulse/netpulse.toml`; event log `~/.local/state/netpulse/events.log`.
- Omitted check fields default: `interval_secs` 10, `timeout_secs` 3, `failures` 2, `critical` true.
- Go target: Fedora 44 workstations; must `go build` cleanly with the five deps above and nothing else.
- Every task ends with `go build ./... && go test ./...` green, then a commit.

package state

type Severity int
const (
    SevOk       Severity = iota // green
    SevDegraded                 // amber
    SevDown                     // red
)

type Iface struct {
    Name    string
    Up      bool
    MTU     int
    IPv4    string // "" if none
    RxBps   uint64 // bytes/sec since last snapshot
    TxBps   uint64
}
type SysSnap struct { Ifaces []Iface; Err error }

type VpnSnap struct {
    Active      []string // active vpn/tun connection names
    Unavailable bool     // NetworkManager unreachable
}

type Peer struct{ Name, IP string; Online, Exit bool }
type TailscaleSnap struct {
    Backend  string // "Running", "Stopped", "NeedsLogin", "unavailable"
    SelfIP   string
    ExitNode string // "" if none
    Peers    []Peer
}

type Result struct {
    Name     string
    Ok       bool
    Critical bool
    Latency  time.Duration
    Err      string
}
type HealthSnap struct{ Results []Result }

type EventKind int
const (
    EvNone EventKind = iota
    EvRouteMissing
    EvRouteOk
    EvVpnChanged
    EvTailscaleChanged
    EvCheckDown
    EvCheckUp
    EvConfigReloaded
    EvSourceUnavailable
)
type Event struct {
    Kind    EventKind
    Subject string // check name, connection id, prefix
    Detail  string
}

type Store struct {
    mu        sync.Mutex
    sys       SysSnap
    vpn       VpnSnap
    ts        TailscaleSnap
    health    HealthSnap
    subs      []chan Event
}

func NewStore() *Store
func (s *Store) CommitSys(n SysSnap) []Event
func (s *Store) CommitVpn(n VpnSnap) []Event
func (s *Store) CommitTailscale(n TailscaleSnap) []Event
func (s *Store) CommitHealth(n HealthSnap) []Event
func (s *Store) EmitConfigReloaded()
func (s *Store) Emit(e Event)                    // ad-hoc event fan-out (no snapshot diff)
func (s *Store) Subscribe() chan Event          // buffered cap 64; fan-out on each commit
func (s *Store) Snapshot() (SysSnap, VpnSnap, TailscaleSnap, HealthSnap)
func (s *Store) Severity() Severity
```

- [ ] **Step 3: implement state.go**

Store keeps previous snapshots; each `Commit*` diffs prev vs new under `s.mu`, replaces prev, returns events, and non-blocking-fans them out to `s.subs` (`select { case ch <- ev: default: }`).

Diff rules:
- Health: compare by `Name`. Prev missing → treat as baseline (no event). `ok→!ok` → `EvCheckDown{Subject:name, Detail:Err}`; `!ok→ok` → `EvCheckUp{Subject:name}`.
- Vpn: set difference on `Active` — each dropped name → `EvVpnChanged{Subject:name, Detail:"dropped"}`; each added → `Detail:"up"`. `Unavailable` flipping to true → `EvSourceUnavailable{Subject:"networkmanager"}`.
- Tailscale: `Backend` change → `EvTailscaleChanged{Detail: old+"→"+new}`.
- Sys: `Err` set when prev unset → `EvSourceUnavailable{Subject:"sysnet"}`. Routes are NOT part of SysSnap; `internal/routes` (Task 6) calls a dedicated commit method instead.

Add to Store:

```go
// routesPrev tracks which watched prefixes were present last commit.
routesPrev map[string]bool
```

```go
// CommitRoutes: missing = watched prefixes absent from the routing table.
func (s *Store) CommitRoutes(missing []string) []Event
```
Diff prev-missing set vs new: newly missing → `EvRouteMissing{Subject:prefix}`; recovered → `EvRouteOk`. Initialize `routesPrev` in `NewStore`; first commit establishes baseline silently.

`Severity()` rules:

```go
// SevDown: any critical check down, ts.Backend in {"Stopped","NeedsLogin"},
//          or default route missing (tracked via CommitRoutes("default")).
// SevDegraded: non-critical check down, any Unavailable source, or
//              ts.Backend == "unavailable".
// else SevOk.
```

Implement `Severity` by iterating current snapshots + a `defaultRouteMissing bool` flag maintained by `CommitRoutes` (subject `"default"`). Keep the flag simple: `CommitRoutes` sets `s.defaultMissing` when `"default"` ∈ missing.

`EmitConfigReloaded` sends `EvConfigReloaded` to subs (no snapshot change).
`Emit(e)` is the escape hatch for events that don't come from a snapshot diff
(e.g. invalid TOML on reload): non-blocking fan-out to all subscribers.

package health

type Prober func(ctx context.Context, timeout time.Duration) (latency time.Duration, err error)

// ForCheck builds a Prober for one check. dns uses cfg.DNS; unknown type → error.
func ForCheck(c config.Check, dnsTargets, dnsServers []string) (Prober, error)

// Run launches one goroutine per check; results feed store via snap accumulate-commit.
// Cancel ctx to stop all check goroutines (config reload calls this).
func Run(ctx context.Context, checks []config.Check, dnsTargets, dnsServers []string, store *state.Store)
```

Counter logic (per check): consecutive probe failures; emit `Result{Ok:false}` only when count >= `Failures`; on success reset count, emit `Result{Ok:true}` (with `Latency`). Worker-internal errors (constructor failure) are reported once as `Result{Ok:false, Err:"prober: ..."}` and the goroutine exits — they never enter the failure counter. (`ponytail: results are accumulated in a shared map under mutex and committed on each goroutine's tick — O(#checks) copy per tick, fine at tens of checks.`)

```go
func tcpProber(target string) Prober {
    return func(ctx context.Context, to time.Duration) (time.Duration, error) {
        d := net.Dialer{Timeout: to}
        start := time.Now()
        conn, err := d.DialContext(ctx, "tcp", target)
        if err != nil { return 0, err }
        conn.Close()
        return time.Since(start), nil
    }
}

func httpProber(target string) Prober {
    // target: URL; 200-399 = ok
    client := &http.Client{CheckRedirect: func(*http.Request, []*http.Request) error {
        return http.ErrUseLastResponse // don't follow; 3xx already ok
    }}
    return func(ctx context.Context, to time.Duration) (time.Duration, error) {
        req, _ := http.NewRequestWithContext(ctx, "GET", target, nil)
        start := time.Now()
        resp, err := client.Do(req) // ctx carries timeout
        if err != nil { return 0, err }
        resp.Body.Close()
        if resp.StatusCode >= 400 { return 0, fmt.Errorf("status %d", resp.StatusCode) }
        return time.Since(start), nil
    }
}

func dnsProber(targets, servers []string) Prober {
    return func(ctx context.Context, to time.Duration) (time.Duration, error) {
        start := time.Now()
        for _, name := range targets {
            if len(servers) == 0 {
                if _, err := net.DefaultResolver.LookupHost(ctx, name); err != nil { return 0, err }
            } else {
                r := &net.Resolver{PreferGo: true, Dial: func(ctx context.Context, _, _ string) (net.Conn, error) {
                    return (&net.Dialer{Timeout: to}).DialContext(ctx, "udp", servers[0]+":53")
                }}
                if _, err := r.LookupHost(ctx, name); err != nil { return 0, err }
            }
        }
        return time.Since(start), nil
    }
}

func icmpProber(target string) Prober {
    return func(ctx context.Context, to time.Duration) (time.Duration, error) {
        p, err := ping.NewPinger(target)
        if err != nil { return 0, err }
        p.Count = 1
        p.Timeout = to
        p.SetPrivileged(false) // unprivileged datagram socket — Fedora default permits
        start := time.Now()
        if err := p.RunWithContext(ctx); err != nil { return 0, err }
        st := p.Statistics()
        if st.PacketsRecv == 0 { return 0, errors.New("no reply") }
        _ = start
        return st.AvgRtt, nil
    }
}

```go
package main

func main() {
    cfgPath := config.Path()
    _ = config.Ensure(cfgPath)
    cfg, err := config.Load(cfgPath)
    if err != nil { log.Fatal(err) }

    ctx, cancel := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
    defer cancel()

    store := state.NewStore()

    // alerter
    var as []alert.Alerter
    if conn, err := dbus.SessionBus(); err == nil { as = append(as, alert.NewNotify(conn)) }
    if cfg.General.LogEvents {
        if l, err := alert.NewLog(stateLogPath()); err == nil { as = append(as, l) }
    }
    al := alert.Multi(as...)
    go func() { for e := range store.Subscribe() { al.Alert(e) } }()

    // workers
    go sysnet.Poll(ctx, time.Duration(cfg.General.IfaceIntervalSecs)*time.Second, store) // wraps Scan each tick; add thin Poll fn in sysnet
    go routes.Poll(ctx, 5*time.Second, append([]string{"default"}, cfg.General.Routes...), store)
    go vpn.Watch(ctx, store)
    go tailscale.Poll(ctx, time.Duration(cfg.General.TailscaleIntervalSecs)*time.Second, store, nil)
    hcCtx, hcCancel := context.WithCancel(ctx)
    defer hcCancel()
    go health.Run(hcCtx, cfg.Checks, cfg.DNS.Targets, cfg.DNS.Servers, store)

    // config reload — shared by fsnotify watch and the tray menu item
    doReload := func() {
        nc, err := config.Load(cfgPath)
        if err != nil {
            store.Emit(state.Event{Kind: state.EvConfigReloaded, Detail: "config invalid, keeping previous"})
            return
        }
        cfg = nc
        hcCancel()
        hcCtx, hcCancel = context.WithCancel(ctx)
        go health.Run(hcCtx, cfg.Checks, cfg.DNS.Targets, cfg.DNS.Servers, store)
        store.EmitConfigReloaded()
    }
    unwatch, _ := config.Watch(cfgPath, func(*config.Config) { doReload() }) // watch fires doReload which re-loads itself
    defer unwatch()

    // tray (blocks); menu unavailable → notify-only
    if err := tray.Run(ctx, store, doReload, cancel); err != nil {
        log.Printf("tray unavailable, notify-only: %v", err)
        <-ctx.Done()
    }
}

// stateLogPath returns ~/.local/state/netpulse/events.log, creating the dir.
func stateLogPath() string {
    dir := filepath.Join(os.Getenv("HOME"), ".local", "state", "netpulse")
    os.MkdirAll(dir, 0755)
    return filepath.Join(dir, "events.log")
}
```

Note: `config.Watch`'s `reload` callback signature takes the parsed config — when
nil it means parse failed; `doReload` re-runs `Load` itself so both paths funnel
through one function (watch passes its parsed cfg only as a hint; simplest is to
always re-load inside `doReload` and ignore the callback arg, as written).
}
```
